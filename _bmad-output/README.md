# 工程输出与历史资产导航

本目录保存 solo-distill-mcp 工具工程的历史材料和独立来源蓝图，不是另一套治理根或当前任务账本。读取历史材料不授予恢复、重放、修改、接受或归档权限。

## 目录职责

- [历史架构决策](adrs/)：保留决策原件；通过[工具工程 ADR 索引](../docs/adrs/README.md)定位，不能因目录治理改变原件状态或正文。
- [历史分析](analysis/)：保留分析原件；通过[分析索引](../docs/analysis/README.md)按需阅读，建议与推断不直接登记为事实。
- [归档计划](archive/plans/)：保留已归档实例的契约和历史授权，不自动恢复最新计划，也不修补归档正文中的旧路径。
- [独立来源蓝图](blueprints/)：保存来源扫描生成的候选包，与工具自身规范分开；生成、结构认证和传输不证明人工语义接受、来源安装或宿主加载。
- [机器证据目录](../verification/)位于本目录之外，保存历史回执、失败现场及完整输出，继续保留原路径与原字节。

## 工具工程入口

- [公共协作入口](../AGENTS.md)与[项目说明](../README.md)定义阅读导航和版本边界。
- [治理索引](../specs/governance/00-index.md)按职责定位权限、生命周期、契约、验证及交付规范；本页不复制完整规范。
- [领域导航](../specs/domains/00-index.md)定位实现、调用方和副作用边界。
- [任务薄指针](../specs/tasks/_active.md)只定位获准契约，不保存阶段状态或通过记录；空值不触发历史恢复。
- [项目事实基线](project-context.md)只登记有证据和适用范围的事实；创建或更新须获得相应写入授权，不保存当前 Git 分支、待提交列表或逐轮流水。

## 保留与证据边界

- 历史决策、分析、归档计划、机器凭据及独立蓝图均不得因本次目录治理修改、重命名、搬迁或删除；新导航引用原件，不替换原件。
- [主线 A 完成回执](../verification/mainline-a-schema-v3-20261030T095713Z/phase6-7-closeout-20261102.completion.receipt.json)记录该特定实例的收尾，明确人工语义审核未执行／未证明、宿主加载未证明；不代表全部历史提案或能力均已完成。
- 完成回执中的摘要关联具体文件版本。历史收尾前后的摘要可能不同，不将旧绑定摘要强套到收尾后的原件；复读历史回执不等于重新执行其业务验证。
- 当前进度只使用覆盖已核验的控制器或平台任务记录，本目录说明、计划和 ADR 都不是第二份运行账本，也不证明程序防篡改。
- [Git 忽略规则](../.gitignore)为本目录与机器证据目录保留可见性例外，避免通用缓存或草稿规则隐藏未跟踪证据；例外不授予提交、上传或删除权限。
- 本地保留、纳入版本控制、GitHub 上传与来源分发分别判断。上传前须审查来源正文、敏感内容、附件分发权限及可达提交历史，不以目录名称或本地提交成功代替授权。
- 文档运维只采用获准的差异、链接、格式与完整性检查，不默认运行全库测试、来源扫描、在线窗口、网关或宿主。
